# Q3考高斯刷题 v1.0.0 内部发布材料

这是一套供内部教师直接使用的发布材料，适用于 Windows、macOS、Android 和内部网页服务。所有应用包均内嵌统一的坚果云与 AI 配置，请勿对外分发。

## 目录说明

- `01_Windows桌面端`：安装版和免安装版，普通 Windows 用户优先下载安装版。
- `02_macOS免安装版`：Apple 芯片与 Intel 两个内置运行时包，无需安装 Node.js。
- `03_Android安卓端`：内部 APK，适合手机和平板侧载安装。
- `04_网页部署`：带本地代理和一键启动脚本的内部网页包；无需预装 Node.js，首次缺少运行时时会自动下载并创建桌面快捷方式。
- `05_项目介绍PPT`：中文功能介绍与中文迭代过程介绍。
- `06_功能截图`：可用于内部汇报或制作不含下载链接的演示视频。
- `07_说明文档`：安装、功能、隐私、更新日志、发布文案、检查清单，以及同版的一页 A4 使用指南 PDF 与高清 PNG。
- `SHA256校验码.txt`：验证下载文件是否完整。

## 内部分发边界

Windows、Mac、Android 和网页包都已经内嵌统一的坚果云账号、应用密码和 AI API Key，内部成员安装后可直接使用。禁止把安装包、压缩包、管理配置截图或解压后的网页资源上传到公开网盘、B站附件、代码仓库或群外渠道。

Windows 包未购买商业代码签名证书，首次运行可能触发 SmartScreen 提示；请先核对 SHA-256，再选择“更多信息 → 仍要运行”。Android 包为内部侧载版，不是应用商店签名包。
