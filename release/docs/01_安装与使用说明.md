# 安装与使用说明

## Windows

### 安装版（推荐）

1. 运行 `Q3考高斯刷题_1.0.0_Windows内部安装版_x64.exe`。
2. 选择安装目录并完成安装。
3. 从桌面或开始菜单打开“Q3考高斯刷题”。

### 免安装版

直接运行 `Q3考高斯刷题_1.0.0_Windows内部免安装版_x64.exe`。首次启动需要解压运行时，速度会比安装版稍慢。

支持 64 位 Windows 10/11。桌面版无需另装 Node.js。

## Android

1. 将 APK 传到手机。
2. 在系统设置中临时允许当前文件管理器“安装未知应用”。
3. 安装后关闭该权限。
4. 打开“Q3考高斯刷题”。

内部 APK 用于侧载；不得上传应用商店或公开下载站。若后续公开上架，需要重新生成不含内部配置并使用正式私有签名的版本。

最低支持 Android 7.0（API 24），推荐 Android 10 或更高版本。

## 网页版

解压网页部署包后直接双击“启动网页服务.cmd”。脚本会自动检测 Node.js；没有可用版本时会下载并校验官方免安装运行时，随后打开浏览器并在桌面创建快捷方式。双击“停止网页服务.cmd”可关闭后台服务。服务器部署方法见包内“网页部署说明.md”。

## macOS

- M1/M2/M3/M4/M5 等 Apple 芯片使用 `arm64` 包；较老 Intel Mac 使用 `x64` 包。
- 解压后双击“启动Q3刷题.command”，无需安装 Node.js、Homebrew 或开发工具。
- 若首次运行被 macOS 拦截，请按住 Control 点击启动文件并选择“打开”，详情见包内说明。

## 首次登录

- 默认管理员：`admin`
- 初始密码：`1415926`

首次登录后请立即在管理中心修改管理员密码，再添加教师账号。若部署到局域网或公网，这一步不可省略。

## 云同步与 AI

内部版已经内嵌坚果云 WebDAV 账号、应用密码和 AI API Key，安装后无需逐台填写。管理中心仍可查看和更新统一配置，但不要把配置页面截图发给外部人员。若统一密钥更换，应重新构建内部包或由管理员在各设备更新。
