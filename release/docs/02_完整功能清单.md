# 完整功能清单

## 题库与刷题

- 479 道高思奥数题，覆盖三年级、五年级、六年级重点章节。
- 兴趣篇、拓展篇、超越篇分层训练。
- 卡片刷题、章节刷题、模块筛选和关键词定位。
- 顺序、完全随机、章节内随机、错题优先随机等可选随机模式与范围。
- 题目原图、答案切片、文字答案与精讲组合展示。

## AI 教研辅助

- 无完整原书解析时自动生成核心思路、分步解答、最终答案和教学避坑。
- 题图视觉识别与官方答案核验。
- 拍照录入、答案识别和人工确认机制。
- 多模型失败回退、本地解析兜底、超时提示与结果缓存。

## 学情与复习

- 正确、错误、跳过、收藏、答题用时等学习记录。
- 个人错题本、团队错题统计和艾宾浩斯复习。
- 排行榜、学情战报、统考倒计时和 200+ 数学家名言轮播。
- 学情 CSV、海报、PDF 和分享文件导出。

## 试卷与打印

- 按年级、章节、模块、难度和数量组卷。
- 标准 A4 PDF、系统打印、高清长图和整卷文字复制。
- 大题跨页分页、题图等比例缩放、答案解析区和评分栏。
- 手机端文件分享与失败时下载回退。

## 账号与数据

- 管理员、教师账号和密码管理；支持新增、修改姓名与角色、重置密码、软删除及回收站恢复。
- 多管理员成员变更合并和账号隔离。
- 坚果云 WebDAV 多设备同步、ETag 条件写入和冲突合并。
- 删除标记软删除，可恢复，不直接物理删除云端记录。
- 本机数据备份与恢复。

## 多端体验

- Windows 独立桌面端。
- Android 手机/平板端。
- 自建网页服务。
- 响应式界面、移动端底部导航、触控反馈和首汉字头像。
