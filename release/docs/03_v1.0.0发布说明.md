# v1.0.0 发布说明

发布日期：2026-08-17

## 本版重点

- 完成 479 道题、932 个题图引用的完整性校验。
- 修复多批题目与答案切片跨页、半页、串题和题号错配问题。
- 为缺少可用原书答案图的题目补充本地解析与 AI 自动精讲。
- 新增可配置随机刷题、200+ 数学家名言、学情海报、CSV、PDF 与长图导出。
- 改进移动端分享、CSV 导出、AI 状态反馈和头像显示。
- 完成多管理员数据隔离、云端软删除、跨设备 ETag 冲突合并。
- 修复无答案切片题自动 AI 请求自我取消并永久卡住的问题。
- 新增 Windows 安装版/免安装版、Mac Apple 芯片版/Intel 版、Android 内部版和网页部署包；各平台均内嵌统一同步与 AI 配置。

## 已验证

- 自动测试：107 项通过。
- 题库资源：479 道题、932 个题图引用通过。
- Windows 打包后自检：首页与题库均返回 200，读取 479 道题。
- 内部构建扫描：坚果云账号、应用密码和 AI Key 三项配置均已嵌入各平台运行资源。

## 使用限制

- AI 和坚果云属于第三方服务，网络异常、额度耗尽或上游 5xx 时会降级或提示重试。
- Windows 包未使用商业代码签名证书，可能出现 SmartScreen 提示。
- Android 文件为侧载内部版；应用商店发布必须重新生成不含内部配置的正式签名版本。
- Mac 免安装包无需 Node.js，但未经过 Apple Developer ID 签名和公证，首次运行可能需要在“隐私与安全性”中确认。
- 自建网页若对公网开放，必须配置 HTTPS、修改默认管理员密码并限制管理入口。
