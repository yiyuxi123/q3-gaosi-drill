# 隐私与数据安全说明

## 数据存放

- 未开启云同步时，账号配置、学习记录、错题和计划主要保存在当前设备浏览器/应用存储中。
- 开启坚果云后，团队成员、公告、个人学习记录和计划会写入管理员指定的 WebDAV 目录。
- 删除账号时云端文件写入可恢复的删除标记，不直接物理删除；管理员可通过恢复流程回滚。

## AI 数据

使用 AI 解析或拍照识别时，相关题目文字、题图或用户选择的照片会发送至管理员配置的第三方 AI 服务。请勿上传含学生姓名、手机号、住址等不必要个人信息的照片。

## 内部版凭据

内部发布版在 Windows、Mac、Android 和网页包中内嵌统一的坚果云账号、应用密码和 AI API Key，以降低内部成员配置门槛。任何获得安装包或解压资源的人都可能提取这些凭据，因此只能在受控内部渠道分发；不得把真实凭据、管理配置截图或安装包用于公开视频附件和公开文档。

## 管理员责任

- 首次登录后立即修改默认管理员密码。
- 仅向可信教师分配管理员权限。
- 定期导出备份并检查云同步状态。
- 对公网部署时启用 HTTPS、访问控制和服务器日志保护。
