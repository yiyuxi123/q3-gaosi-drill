# 发布前检查清单

## 文件

- [ ] Windows 安装版可启动。
- [ ] Windows 免安装版可启动。
- [ ] Android APK 可安装并打开。
- [ ] 网页部署包可解压并启动。
- [ ] 两份 PPT 可以正常播放。
- [ ] 截图中没有账号、应用密码、API Key 或学生个人信息。
- [ ] SHA-256 校验码与实际文件一致。

## 账号与安全

- [ ] 四个平台包均通过内部配置嵌入检查。
- [ ] 发布文案明确说明内部包不得公开下载。
- [ ] 文档要求首次登录后修改管理员默认密码。
- [ ] 未将 `.env.local`、源码调试页、原始审图页或临时文件放入发布目录。

## 内容与体验

- [ ] 首页、登录、刷题、答案、错题本、组卷和管理中心可打开。
- [ ] 随机模式及范围选择可用。
- [ ] AI 未配置时有清晰提示或本地兜底。
- [ ] 打印、PDF、长图、CSV 和分享至少各验证一次。
- [ ] 手机端按钮有加载、成功或失败反馈。

## 对外发布

- [ ] B 站标题、简介、标签、章节和置顶评论已填写。
- [ ] B 站视频和简介没有附内部包下载链接。
- [ ] 内部下载链接限制为指定成员访问，不允许匿名下载或编辑。
- [ ] 保留 v1.0.0 原始包，后续版本不要直接覆盖。
