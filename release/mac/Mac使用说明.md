# Mac 免安装版使用说明

## 选择版本

- M1、M2、M3、M4 等 Apple 芯片：选择 `arm64` 包。
- 较老的 Intel Mac：选择 `x64` 包。
- 不确定时，点击屏幕左上角“ → 关于本机”查看“芯片”或“处理器”。

## 启动

1. 解压 ZIP，不要只在压缩包预览窗口中运行。
2. 打开解压后的“Q3考高斯刷题”文件夹。
3. 双击“启动Q3刷题.command”。
4. 浏览器会自动打开系统页面；使用期间不要关闭随之出现的终端窗口。

本包已经内置 Node.js 官方运行时，无需安装 Node.js、Homebrew 或任何开发工具。

## macOS 安全提示

此包未经过 Apple Developer ID 签名和公证。若系统阻止首次运行：

1. 按住 Control 键点击“启动Q3刷题.command”，选择“打开”；
2. 或进入“系统设置 → 隐私与安全性”，确认允许本次运行；
3. 只使用发布目录中的原始文件，并先核对 SHA-256。

如仍无法启动，可在文件夹空白处打开终端，运行：

```bash
chmod +x "启动Q3刷题.command" runtime/node
./启动Q3刷题.command
```

本包为内部版，已经内嵌统一的坚果云账号、应用密码和 AI Key，安装后可直接同步和使用 AI。请勿将压缩包、管理配置截图或解压后的程序目录发送给外部人员。
