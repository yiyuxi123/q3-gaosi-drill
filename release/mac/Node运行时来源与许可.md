# Node.js 运行时来源与许可

本免安装包内置 Node.js v24.19.0 LTS，仅用于启动本地网页服务。

- 官方来源：`https://nodejs.org/dist/v24.19.0/`
- 构建时会下载官方 macOS `darwin-arm64` 或 `darwin-x64` 归档；
- 构建脚本使用官方 `SHASUMS256.txt` 验证 SHA-256；
- Node.js 的原始 `LICENSE` 文件随包附带在 `runtime/LICENSE`。

Node.js 是 Node.js contributors 的商标与开源项目，本项目不对其进行修改。
