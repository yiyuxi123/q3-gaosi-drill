# 网页部署说明

## 本机启动

1. 双击“启动网页服务.cmd”，无需预先安装任何软件。
2. 脚本会自动检测 Node.js；设备没有可用版本时，会从 Node.js 官方网站下载免安装运行时并校验完整性。
3. 启动成功后会自动打开浏览器，并在桌面生成“Q3考高斯刷题”快捷方式。
4. 需要停止后台服务时，双击“停止网页服务.cmd”。

首次缺少运行时时需要联网下载，后续启动不再重复下载。不要移动包内的单个文件；如需换位置，请移动整个解压后的文件夹。

## 服务器部署

- 启动命令：`npm start`
- 默认监听：`127.0.0.1:5173`
- 局域网监听：将环境变量 `HOST` 设为 `0.0.0.0`
- 修改端口：设置环境变量 `PORT`
- 对公网提供服务时，必须在前方配置 HTTPS 反向代理，并在首次登录后立即修改管理员默认密码。

本网页包为内部版，已内嵌统一的坚果云账号、应用密码和 AI Key。仅可部署在受控内部设备或网络，不得上传公共静态托管、公开网盘或代码仓库。
